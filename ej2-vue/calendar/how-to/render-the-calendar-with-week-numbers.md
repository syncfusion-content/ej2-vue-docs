# How to show week numbers in Vue Calendar

You can enable `weekNumber` in the Calendar by using the [`weekNumber`](https://ej2.syncfusion.com/vue/documentation/api/calendar/index-default#weeknumber) property. This displays the week-of-year numbers in a leading column of the Calendar. The default value is `false`.
